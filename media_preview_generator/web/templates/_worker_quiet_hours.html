Global pause schedule (Quiet Hours) off

Pause all processing, including current files. Scheduled runs during a global pause are skipped; manual and webhook jobs may queue. Missed scheduled runs are not caught up automatically.

Times use the app timezone. Days select when a window starts: Monday 23:00–07:00 ends Tuesday. Existing windows were preserved on upgrade. Manual Pause All stays active until you resume it; opening worker groups does not clear it. Group hours only stop new files and let current work finish.
