# Loudness per-library language filter: only chosen audio languages are analysed
Status: draft
Issue: none (fork; upstream-bound later, no PR without approval)
Base: upstream/dev 0cc6a60. Cited lines are the working tree (prod/thevault); `loudness/job.py` differs from upstream/dev only in the progress callback (lines 260-285), `plex_db.py`, `settings.py`, the web files and tests are identical.

## Goal
Per Plex library the user picks languages (autocomplete on English names, stored as ISO 639-2/B codes) and whether untagged audio is analysed; a loudness job analyses only those streams, marks the item done when every wanted stream has loudness, and reports it `loudness_up_to_date` on later runs; no choice = today's behaviour.

## Decisions
- Per library (user, 2026-10-06): both the language list and the unknown-language choice are per library. The unknown choice is not global: it costs nothing extra (one field in the same per-library object) and a kids library with untagged Swedish dubs wants "analyse" while a catalogue of untagged foreign films wants "skip".
- Setting shape, in the existing per-server block (E8): `media_servers[].loudness.library_languages = {"<library_id>": {"languages": ["swe", "eng"], "analyse_unknown": true}}`. A library without an entry, or an entry with an empty list and `analyse_unknown: true`, analyses every stream (today). Key absent when nothing restricts anything (keeps E12 asserts and stored configs unchanged).
- Canonical code = ISO 639-2/B (`ger`, `fre`, `chi`; E11), so every stored rule is one 3-letter code. Resolution accepts, case-insensitively and after cutting a `-`/`_` region or script subtag (E15: `en-US`, `sv-SE`, `es-419`, `zh-TW`, `pt-BR`): 639-1 (`en`, `sv`, `no`), 639-2/B and /T, the lower-cased English name (`english`, E15), and the aliases `scr`→`hrv`, `scc`→`srp` (withdrawn codes still in old tags), `nb`/`nob`→`nor` (user: Bokmål counts as Norwegian). Unknown = NULL/empty, `und`, `zxx`, `mul`, `unknown` (E15), the `qaa-qtz` range, or anything else not resolvable (639-3 such as `yue`).
- A stream on a server is wanted when any matching library's rule wants it (a file in two libraries of one server).
