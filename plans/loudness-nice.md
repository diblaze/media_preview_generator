# Job-kind priority setting (previews / Intro & Credits / loudness rank 1-3) plus nice 10 for loudness ffmpeg
Issue: diblaze/media_preview_generator#8
Status: done

## Goal
A `job_kind_priority` setting ranks each job kind 1-3 (default all 1 = today's dispatch, nothing changes until set); a worse-ranked kind starts no new file while a better-ranked kind has eligible queued work (unchecked/queued items, job not paused, an open worker group that may run it), in-flight files finish, and the worse kind resumes by itself when that work drains; loudness ffmpeg additionally runs at `nice 10`. On thevault: previews 1, Intro & Credits 1, loudness 2 via the API.
